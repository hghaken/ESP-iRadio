# Schematic generators

The Rev B schematic (`../esp-iradio.kicad_sch` + `../power_usb.kicad_sch`) is generated by these
scripts, so a change is made here and the sheets are written again; the scripts check the field
placement as they go.

| File | Purpose |
|---|---|
| `schgen.py` | small KiCad 9 schematic writer: symbols from the project/KiCad libraries, wires with automatic junctions, power symbols, local and global labels, a sheet symbol, sub-sheet instance paths |
| `fieldcheck.py` | warns about reference/value texts that overlap each other, cross a wire or sit on a symbol |
| `gen_radio.py` | sheet 1 (root): ESP32-WROVER-IE, display panel, microSD, encoder, audio |
| `gen_power.py` | sheet 2: USB-C, CH340C + auto-reset, BQ24074 charger, cell protection, regulators, on/off switch |
| `intcheck.py` | checks an exported netlist against `../../07-integrated-board.md` (expected connections, no shorts between the rails) |

Run from this folder (Python 3, no packages needed; `PRJ` = the KiCad project folder):

```
python gen_power.py ..
python gen_radio.py ..
kicad-cli sch erc --severity-all -o erc.rpt ../esp-iradio.kicad_sch
kicad-cli sch export netlist --format kicadsexpr -o board.net ../esp-iradio.kicad_sch
python intcheck.py board.net
```

Expected: ERC 1 warning (the MAX98357A exposed pad, pin type unspecified, on GND) and `OK` from
`intcheck.py`. Close the schematic in KiCad first. Once the board is edited by hand in KiCad
(layout started, symbols moved), stop regenerating: the scripts overwrite both sheets.
